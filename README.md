# 메뉴 수익 분석기 | 배달앱 수수료 계산기

배민, 쿠팡이츠, 요기요에서 메뉴를 팔았을 때 수수료·배달비·용기값 등을 뺀 **실제 순수익**을 바로 계산해주는 무료 웹 도구입니다. 설치나 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

## 사용설명서

### 1. 정보 입력

1. **① 어느 플랫폼에서 파시나요?**
   배민 / 쿠팡이츠 / 요기요 / 직접입력 중 하나를 선택하면 해당 플랫폼의 기본 중개수수료율·결제수수료율이 자동으로 적용됩니다.
   - 배민·쿠팡이츠는 매장 매출 순위에 따라 수수료가 2.0~7.8%로 달라지므로, 정확한 수수료는 정산서를 확인한 뒤 "수수료율 직접 수정"에서 바꿔주세요. (부가세 10% 별도)
2. **② 메뉴 판매가**를 원 단위로 입력합니다. (예: 18,000)
3. **③ 음식 원가**를 입력합니다. (예: 5,500)
4. **④ 추가 비용 입력 (선택사항)** 을 펼치면 배달비 부담액, 용기값, 포장비를 각각 입력할 수 있습니다.
5. 필요하면 **수수료율 직접 수정 (고급)** 을 펼쳐 중개수수료율·결제수수료율을 직접 입력할 수 있습니다.

값을 입력하는 즉시 결과가 자동으로 계산됩니다. **계산하기** 버튼을 누르면 현재 결과가 "최근 계산 기록"에 저장됩니다. **초기화** 버튼으로 모든 입력값을 지울 수 있습니다.

### 2. 계산 결과

- **실제로 내 통장에 남는 돈**: 판매가에서 모든 비용(원가, 수수료, 배달비, 용기값, 포장비)을 뺀 순수익 금액과 순이익률, 원가율을 보여줍니다.
- **비용 내역**: 각 비용 항목을 금액 또는 비율(%) 단위로 전환해서 볼 수 있습니다.
- **비용 구성 비율**: 도넛 차트로 판매가 대비 각 비용과 남는 돈의 비중을 시각적으로 보여줍니다.
- **최근 계산 기록**: "계산하기"를 누를 때마다 계산 시간, 플랫폼, 판매가, 순수익, 순이익률이 표 형태로 쌓입니다. **전체 삭제**로 기록을 지울 수 있습니다.

### 3. 수익 분석 리포트

입력한 메뉴의 원가율, 순이익률, 배달비 비중, 플랫폼 비용 비중을 자동으로 분석하고 종합 평가(예: 양호/주의 등급)를 알려줍니다.

- **다른 플랫폼이면 얼마나 다를까?**: 같은 판매가·원가 기준으로 배민 / 쿠팡이츠 / 요기요 각각의 순수익을 나란히 비교하고, 가장 유리한 플랫폼에 "최고" 배지를 표시합니다.

### 4. 예상 월 순수익

**하루 판매 수량**과 **월 판매일 수**를 입력하면, 위에서 계산한 메뉴 1개당 순수익을 기준으로 예상 월 순수익을 자동 계산합니다.

### 얼마에 팔아야 할까? (접이식 섹션)

목표로 하는 원가율을 정해두고 있다면, 이 섹션에서 플랫폼·원가·용기값·포장비·배달비·목표 원가율을 입력해 **역산으로 권장 판매가**를 구할 수 있습니다.

## 참고 사항

- 입력한 정보와 계산 기록은 서버로 전송되지 않고 내 브라우저(localStorage)에만 저장됩니다. 다른 기기·브라우저와는 공유되지 않습니다.
- 모든 수수료율은 참고용입니다. 정확한 수수료는 반드시 플랫폼 정산서에서 확인하세요.

## 개발/배포

정적 웹 페이지(HTML/CSS/JS)로 구성되어 있어 별도 빌드 과정 없이 `index.html`을 브라우저로 열거나 정적 호스팅에 그대로 배포하면 됩니다.

- `index.html` — 페이지 구조
- `style.css` — 스타일
- `script.js` — 계산 로직 및 인터랙션
